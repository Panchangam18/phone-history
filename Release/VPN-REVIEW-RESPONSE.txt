Phone History uses NEPacketTunnelProvider as a local transport to developer services on the same iPhone. It is not an external internet VPN or proxy. Its only included IPv4 route is 10.7.0.1/32; the default internet route is excluded. There is no remote VPN exit server or developer-operated backend.

1. What information is collected using the VPN?
The app does not log ordinary internet packets, DNS requests or network browsing traffic. Through authenticated local developer services, it reads accessibility text/metadata and temporary screenshot frames of the current screen. Vision OCR converts frames to text on the phone; automatic capture discards image frames and stores no video. Saved observations contain bounded, deduplicated screen text, timestamps, available app/process labels and evidence references. On-device summaries and local diagnostic counters are also retained. Visible content may contain personal information, such as messages, names, search queries, page titles/URLs or draft text. Capture is partial, not a complete interaction log. It does not intercept keystrokes or touch events, inject input, move accessibility focus or highlight elements.

2. Complete purpose and planned uses
This is an owner-controlled personal activity journal for later recall. The app displays/searches saved context and evidence, and uses Apple's on-device Foundation Models to generate activity memories. The owner can pause capture, delete history and choose retention. Optional desktop access lets the owner export/search history or request current context through their approved desktop and agent tools. A current screenshot requires a separate on-phone screenshot permission. There is no advertising, analytics, sale of data, developer profiling, automatic cloud upload or cloud AI summarization in the iPhone app.

3. Sharing and storage
We receive no captured history, screenshots or analytics. History stays in the iPhone app's shared container, using native iOS file protection. History/trust folders and the diagnostic history mirror are excluded from system backups; this does not remove older backup copies. Default retention is a configurable 512 KiB volume-based sliding window. Identity keys use the native Keychain.

Sharing occurs only when the owner chooses it: an approved desktop requires on-phone fingerprint approval and an authenticated, encrypted direct local-network connection; a user may also explicitly share an export. A separately approved screenshot request returns a point-in-time image to that desktop and does not add it to phone history. Exported data may be stored on the chosen desktop/destination. If the owner gives it to a desktop AI agent, that agent may process it with its provider under the owner's configuration and that provider's policies. The iPhone app supplies no cloud relay. Revoking access blocks future access, not copies already exported.

Capture requires Developer Mode and a one-time pairing record created with the owner's own trusted Mac. Recipient-specific private pairing keys are never bundled or shared with Apple or desktop agents. The owner approves iOS's VPN configuration and can stop capture in the app or Control Center; standard system VPN status remains visible. These are developer-service protocols, not a claimed public cross-app capture API. We disclose this dependency for Apple's eligibility assessment.
