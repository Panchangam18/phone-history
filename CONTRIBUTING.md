# Contributing

Keep capture generic across apps. Avoid website-specific parsers, focus movement, inspector highlighting, touch interception and UI automation as background capture. Preserve user control, bounded storage and explicit desktop approval.

Use your own phone and signing identities. Build config, pairing records, generated projects, logs and build products belong outside Git. Test data must be synthetic. Never publish a signed developer IPA or provisioning profiles as if they were a universal release.

Run the Rust, desktop protocol and decoder tests described in the README. For native changes, also compile the generated Xcode project and document which physical-device behavior was checked. A successful compile is not a successful runtime test. Keep summary assertions grounded in supporting text; displayed content does not prove a click, message, purchase or game outcome.

Original contributions use MIT. Preserve third-party notices and the StosVPN attribution and branding conditions. Do not copy code with incompatible licensing into the project.
